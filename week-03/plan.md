# week-03 계획서 · 키보드 치는 햄스터 펫

## 만들 것
- 화면 오른쪽 아래 구석에서, 내가 타자를 칠 때마다 키보드를 치는 흰 햄스터 펫.
- 그림은 `art/sheet.png` 한 장(2×2, 4칸)을 잘라서 쓴다.

| 칸 | 그림 | 언제 보여 주나 |
|---|---|---|
| ① 왼쪽 위 | 두 손 들기 | 키를 안 누르고 있을 때 (기다림) |
| ② 오른쪽 위 | 한 손 내림 | 키를 누를 때마다 ②, ③ 번갈아 |
| ③ 왼쪽 아래 | 다른 손 내림 | 〃 |
| ④ 오른쪽 아래 | 눈 감음 | 10초 동안 아무 키도 안 누르면 (졸기) |

- 크기: 약 150×150 픽셀, 위치: 작업 표시줄 바로 위 오른쪽 구석.
- 테두리 없이, 배경은 투명하게, 다른 창보다 항상 위에.
- 펫 아래에 "오늘 123타"처럼 누른 횟수를 작게 보여 준다. 끄면 0 으로 돌아간다.
- 펫을 오른쪽 클릭하면 메뉴가 뜨고 "끄기"로 끈다.

## 어디서 돌아가는지
- 내 Windows 컴퓨터 바탕화면에서 돌아간다.
- 만드는 동안에는 `python pet.py` 로 실행하고, 다 만들면 PyInstaller 로 묶어서 더블클릭으로 켜는 `.exe` 파일 하나로 만든다.

## 재료
- Python (이 컴퓨터에는 3.15.0 이 설치돼 있음)
- PySide6-Essentials : 펫 창 (투명 배경, 항상 위, 오른쪽 클릭 메뉴)
- pynput : 키를 눌렀다는 사실 듣기
- Pillow : `sheet.png` 를 4칸으로 자르기
- PyInstaller : `.exe` 하나로 묶기
- 설치 장소: `week-03/.venv` (week-03 전용 가상 환경). 이 폴더는 GitHub 에 올리지 않는다.

## 파일 모양 (예정)
```
week-03/

  art/frame-1~4.png    자른 그림 4장

  pet.py               펫 프로그램
```

## 단계

### 1단계 · 재료 준비
- `week-03/.venv` 가상 환경을 만들고 재료 4개를 설치한다. (설치 직전에 한 번 더 물어보기)
- `week-03/.gitignore` 에 `.venv/`, `build/`, `dist/`, `*.spec` 를 적는다.
- **확인할 것**: 재료 4개가 모두 오류 없이 설치되고, 버전이 보인다. Python 3.15 용 PySide6 가 아직 없으면 여기서 멈추고 어떻게 할지 같이 정한다.
- **커밋**: `week-03: 재료 준비 (.gitignore)`

### 2단계 · 그림 자르기
- `cut.py` 로 `sheet.png` 를 가로세로 반씩 잘라 `art/frame-1.png` ~ `frame-4.png` 를 만든다.
- **확인할 것**: 4장을 열어 봤을 때 햄스터가 잘리지 않고 하나씩 들어 있고, 배경이 투명하다. 순서가 위 표와 맞다.
- **커밋**: `week-03: 그림 4장으로 자르기`

### 3단계 · 펫 띄우기
- `pet.py` 로 ① 그림을 오른쪽 아래 구석에 약 150×150 크기로 띄운다. 테두리 없음, 배경 투명, 항상 위.
- 오른쪽 클릭 → "끄기" 메뉴를 넣는다.
- **확인할 것**: 햄스터만 보이고 네모난 배경이 없다. 작업 표시줄에 가려지지 않는다. 다른 창을 눌러도 펫이 위에 있다. 오른쪽 클릭 → 끄기로 꺼진다.
- **커밋**: `week-03: 펫 창 띄우기와 끄기 메뉴`

### 4단계 · 타자에 맞춰 움직이기
- pynput 으로 키를 누를 때마다 ②, ③ 을 번갈아 보여 주고, 잠깐 멈추면 ① 로 돌아간다.
- 이때 어떤 키인지는 쓰지 않고, "눌렀다"는 사실만 받는다.
- **확인할 것**: 메모장이나 다른 창에서 칠 때도 펫이 손을 번갈아 움직인다. 빨리 쳐도 멈추거나 느려지지 않는다. 코드 어디에도 키 이름을 저장하거나 보내는 줄이 없다.
- **커밋**: `week-03: 타자 칠 때 손 번갈아 움직이기`

### 5단계 · 졸기와 횟수 표시
- 10초 동안 키를 안 누르면 ④ 졸기 그림으로 바꾸고, 다시 치면 깨어난다.
- 펫 아래에 "오늘 123타"를 작게 보여 준다. 끄면 0 으로 돌아간다.
- **확인할 것**: 10초 기다리면 눈을 감고, 키 하나에 바로 깬다. 숫자가 누른 만큼 올라간다. 껐다 켜면 0 부터 시작하고, week-03 안에 새로 생긴 기록 파일이 없다.
- **커밋**: `week-03: 졸기와 누른 횟수 표시`

### 6단계 · .exe 로 묶기
- PyInstaller 로 그림까지 넣어서 `.exe` 하나로 묶는다.
- **확인할 것**: `dist` 폴더의 `.exe` 를 더블클릭하면 검은 명령 창 없이 펫만 뜨고, 3~5단계에서 확인한 것이 모두 그대로 된다.
- **커밋**: `week-03: exe 로 묶는 방법 정리` (`.exe` 파일 자체는 크기가 커서 올리지 않는다)

## 하지 말 것
- 어떤 키를 눌렀는지 저장하거나, 화면에 보여 주거나, 인터넷으로 보내지 않는다. 몇 번 눌렀는지만 센다.
- 누른 횟수도 파일에 남기지 않는다. (끄면 0)
- 계획에 없는 재료를 설치하지 않는다. 필요해지면 먼저 물어본다.
- week-03 폴더 밖의 파일을 건드리지 않는다.
- 한 번에 여러 단계를 만들지 않는다. 한 단계를 만들고 → 확인하고 → 커밋한 뒤 다음 단계로 간다.
- `.venv`, `build`, `dist`, `.exe` 를 GitHub 에 올리지 않는다.
