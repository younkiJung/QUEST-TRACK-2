# week-06 · 바깥 정보를 받아 오는 내 앱

## 주제
- 바깥 정보를 받아 오는 내 앱

## 이번 주 목표
- API 로 오늘 정보를 받아 와 보여 주고, 폰에 설치되는 앱으로 만들기

## 만들 것
- 내 앱: week-06/index.html (아직 만들지 않음)
- 확인 도구: week-06/check/index.html (week-05 에서 복사함. 파일 목록은 아직 week-05 게임 것이라, 앱이 쓰는 파일에 맞게 고쳐서 쓴다)

## 이번 주 규칙
- API 키나 비밀번호는 파일에 적지 않는다.
- 정보를 못 받아 오면 빈 화면 대신 까닭을 보여 준다.
- 답은 한국어로 한다.
